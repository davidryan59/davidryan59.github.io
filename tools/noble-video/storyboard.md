# Noble Polyhedra video storyboard

## Summary

This is a silent 30-second square film about the Noble Polyhedra Explorer.
It matches the dark theme and caption style of the builder page's earlier
Sieve and Aperiodic Tiling Explorer films.

## Format

- 1080 × 1080 pixels, 30 fps, exactly 900 frames.
- Silent H.264 with captions embedded in the picture.
- Dark builder-page theme with Georgia headings and compact control labels.

## Scenes

| Time | Picture |
|---|---|
| 0–4 s | I-2 rotates in the default Aurora, Point and Grain appearance. |
| 4–7 s | gD-3.1 demonstrates Aurora, Prism, Mineral and Orbit colours. |
| 7–13 s | D-5 changes from Glass to X-ray while a cutaway opens. |
| 13–17 s | I-2 shows successive selected faces over its full wireframe. |
| 17–21 s | tO-1.1 shows the faces meeting successive selected vertices. |
| 21–24 s | tI-7.1 combines depth lighting, contours and exploded faces. |
| 24–27 s | A changing disphenoid gives way to a stephanoid crown. |
| 27–30 s | I-2 returns with the explorer address. |
