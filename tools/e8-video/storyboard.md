# E8 explorer video storyboard

## Summary

This is a silent 30-second square film about the E8 Root System Explorer. It
uses the dark builder-page theme and the caption style of the Noble Polyhedra,
Sieve and Aperiodic Tiling Explorer films.

## Format

- 1080 × 1080 pixels, 30 fps, exactly 900 frames.
- Silent H.264 with captions embedded in the picture.
- Dark builder-page theme with Georgia headings and compact control labels.
- Matching first and last Petrie frames for a clean loop.

## Scenes

| Time | Picture |
|---|---|
| 0–4 s | The Petrie projection opens as eight coloured 30-gons. |
| 4–8 s | A pointer pulls the viewing plane through hidden dimensions. |
| 8–12 s | The roots settle into the octagonal projection. |
| 12–16 s | One selected root reveals its 56 neighbours. |
| 16–20 s | All 6,720 edges appear over a slowly moving generic projection. |
| 20–24 s | The order-30 Weyl motion separates the roots into eight Coxeter cycles. |
| 24–27 s | Eight simple roots form the E8 Dynkin diagram. |
| 27–30 s | The Petrie projection returns with the explorer address. |
